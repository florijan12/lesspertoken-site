Get a free LLM cost audit of your repo

Send us a public GitHub repo that calls Claude, GPT, Gemini or open models. We read its LLM calls by hand, find the tokens you pay for without needing them, and reply with the fixes and what each one saves per month.

Request an audit Free for public repos. No signup beyond a GitHub account.

What you get

  • Findings ordered by money saved, each with the file and line it comes from.
  • A before-and-after fix for each one, usually a few lines.
  • A monthly estimate from your own volumes, or a percentage if you'd rather not share them.
  • What you already do well, so you know what not to touch.

The usual suspects: prompt caching that's off or quietly broken, the biggest model doing easy work, no output limit, history that grows without bound, and nightly jobs that could use the batch API at half price.

Request an audit

This opens a prefilled issue on our llm-cost-audit repo for you to check and submit. Issues there are public, so leave out anything private.

How it works

  1. You open the request on GitHub with the form above.
  2. We run our scanner on the repo, then read every flagged call ourselves, because a scanner on its own gets things wrong.
  3. We reply on the issue with the report. We do these by hand, so it can take a few days.
  4. Nothing about your project is published unless you say yes. With your OK, we may write it up like the examples below.

Private code? Run the same checks yourself with the free LLM cost audit skill. It runs on your machine and nothing leaves it.
